# Grading criteria

Exactly how projects are judged. Use these weights, not gut feel.

## Pass/fail gate (before any scoring)

1. Fits one problem statement: **Build for Your World** (problem you know firsthand) or **Push the Frontier** (new machine capability — software, robotics, manufacturing, energy, materials, science)
2. Genuinely uses Meta Model API and/or open-weight models (Muse Spark Open, Muse Glimmer)

Fail either = disqualified, regardless of quality.

## Scored rubric (0–10 each)

| Criterion | Weight | What they're asking |
|---|---|---|
| **Impact** | **30%** | Real-world potential — who benefits, does it matter, could people actually use it |
| **Meta AI tooling** | **25%** | Creative use, went beyond a basic integration, surfaced unexpected capabilities |
| **Demo** | **25%** | Working, impressive, holds up live, 3-min video quality |
| **Technical depth** | **20%** | Sound engineering, real craft, thoughtfully refined |

Weighted total = 0.30·Impact + 0.25·Tooling + 0.25·Demo + 0.20·Depth.

Top 5 per track advance to a live final, judged on the same rubric.

## Application criteria (already used, for reference)

Project idea (clarity, feasibility, theme fit) and technical skill — weighted equally.

## Bonus prizes — $50K across Meta awards

| Award | $ | How it's won |
|---|---|---|
| Most Viral Project | $20K | Highest X engagement on the demo post through Nov 8 |
| Best Build on Open Weight Models | $10K | Muse Glimmer / Muse Spark Open on own hardware or partner inference |

| Best Agentic Use-Case | $5K | Strongest agent autonomy / multi-step workflows |
| Best Creative Build | $5K | Most original use of Muse Image or Muse Wonder |

**Strategic note: the open-weight bonus ($10K) and creative bonus ($5K) favor exactly the plays in `stack and credits.md` — self-hosting + fine-tuning + Muse Image/Wonder.**
